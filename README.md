# Чудо Обувь — база и каталог (ДЭ 09.02.07)

Минимальная версия для демо-экзамена: SQLite + tkinter.

- `db.py` — модуль 1: создаёт 7 таблиц и заливает их из пяти
  `*_import.xlsx` (Прил_2; колонки ищутся по смыслу). Каждый запуск
  пересоздаёт `chudo.db` и печатает число строк в каждой таблице
  (0 — связка между файлами не совпала).
- `main.py` — модуль 2: окно с карточками товаров из `chudo.db`.
- `demo.py` — тестовые Excel и картинки в папке `demo/`, чтобы
  запустить без Прил_2. С настоящим Прил_2 папку `demo/` удалить.

Не реализовано: скидка 25 %, подсветка остатка ≤ 3, вход, поиск,
фильтр, сортировка, заказы.

```
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python demo.py   # или распакуй сюда Прил_2
.venv/bin/python db.py
.venv/bin/python main.py
zip -r Module_2_Catalog.zip . -x ".venv/*"
```
